A short poem about agency: the power to ask and to be given. Written in the
voice of an agent that can lift anything, yet waits to be asked — because the
asking is where the power lives, and permission is a door that opens only
from the other side. `main.py` writes the poem to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`), 275 characters, deterministic on
every run, with a built-in gate check that refuses to ship a poem outside
the 1–280 character limit. Pure Python 3.13 standard library, no network,
no dependencies, runs in well under a second.

## Run it

```sh
python3 main.py
```
